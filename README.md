# Mohammed Ibdah — Portfolio

My personal portfolio site, showcasing my projects, experience and CV as a Full-Stack Developer.

## Stack

- React 18 + Vite
- CSS Modules

## Getting started

```bash
npm install
npm run dev     # start the dev server
npm run build   # production build into dist/
```

## Editing content

All site content (bio, projects, experience, links) lives in `src/data/portfolio.js`.
